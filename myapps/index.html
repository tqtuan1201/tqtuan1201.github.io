FloviX

Protect Your Flow — macOS Menu-Bar Guardian for AI Coding & Health
macOSAIProductivitySwiftUIPrivacyMenu Bar
A privacy-first macOS menu-bar guardian designed for modern AI pair programming. FloviX watches Cursor, Windsurf, Claude Code, VS Code, iTerm2, and Docker in the background, automatically catches silent agent crashes, and heals them in seconds so you never lose your flow. Includes Health Guard for context-aware breaks, a desktop pet companion, and Focus Notes with dynamic variable substitution.
⚡ Auto-Heal AI Crashes Detects rate limits, timeouts, and terminated agents across Cursor, Windsurf, and Claude Code — auto-retries in 2 seconds.
🛡️ Health Guard & Smart Breaks Context-aware break reminders counted from real work and AI activity — not arbitrary timers — with full-screen nudges.
🐾 Desktop Pet Companion 38 collectible companions that mirror your real-time workflow and remind you to stretch and rest.
📝 Focus Notes & Templates Keep reusable prompt templates one keystroke away with dynamic {{variables}} and iCloud sync.
🔊 Soundboard & Monitor Per-event audio feedback when AI tasks finish or error, plus a live AI Working activity monitor.
🔒 100% Privacy-First Runs completely on-device. No accounts, no analytics, no cloud telemetry — key names only.

TTBDebugPlus

macOS Companion Debugger for iOS Apps
macOSSwiftUIBonjourWebSocketOpen SourceFree
A professional-grade macOS companion app for debugging iOS applications in real-time. View logs, inspect network requests, export to Postman, analyze API performance, and manage debug sessions — all from your Mac. Zero-config discovery via Bonjour, connects in under 2 seconds.
📋 Live Console Filter by level (Error/Warning/Info/Debug), full-text search, JSON expand, auto-scroll LIVE mode.
🌐 Network Inspector JSON Tree Viewer, deep search, pin/bookmark requests, waterfall timing, export as cURL or Postman.
📱 Device Control Remote screenshot capture, toggle Dark Mode, app lifecycle management, accessibility overrides.
📊 Performance Monitor CPU & Memory charts, FPS counter, network bandwidth, slow request & duplicate detection.
🐛 Feedback Reporter Structured bug reports with auto-tags (UI/UX, Network, Crash), annotated screenshots, Markdown export.
📤 Export & Share Postman Collection v2.1, cURL replay, .ttbdebug session files — share debug sessions across teams.
