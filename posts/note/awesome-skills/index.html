Most of my blog and app work now happens with an AI agent in the terminal. The agent is smart, but it doesn’t know my way of working. Agent skills fill that gap.

Good skills are spread across hundreds of GitHub repos, and my bookmarks became a mess. So I put the ones worth installing into one catalog you can search and filter, like my blockchain keyword note.

What is an agent skill?

A skill is a folder with a SKILL.md file. The file has a short header, a name and a description, followed by plain Markdown instructions. It can also include scripts and templates.

The agent reads only the name and description at first. It loads the full skill when your task needs it, so you can install many skills without filling the context. Skills follow the open Agent Skills standard, so the same folder works in Claude Code, Codex, GitHub Copilot, Cursor, and more.

How I picked them

I checked every repo on October 7, 2026, and kept a skill only when it had:

  • A real skill: a working SKILL.md, not just a prompt in a README.
  • Recent updates: a commit in the last six months.
  • A clear job: one sentence tells you when to use it.
  • A known license: noted on each card, with the non-open-source ones flagged.

Stars helped me find candidates, but they didn’t decide the list.

Search by name or use case (press /), pick a Need, click tags to narrow down, or filter by agent. The link keeps your filters, so you can share a filtered view.

Two skills that started this list

Diagram Design

Diagram Design makes diagrams that look designed, not auto-generated. It covers 42 diagram types and outputs one HTML file with inline SVG, in light, dark, or editorial style.

It can redraw your draw.io, Mermaid, or Excalidraw files and export PNG or SVG. It can also read your site’s colors and fonts, so the diagram matches your blog. Notice how the messy boxes and crossing lines become one clean flow:

Book to Skill

Book to Skill turns a book (PDF, EPUB, DOCX, and more) into a skill. Instead of a summary, it pulls out frameworks, decision rules, and anti-patterns, split into chapter files the agent loads only when needed.

The last step is the one to watch. The agent doesn’t read the whole book, only the chapter your question needs:

Your agent answers from the book you trust instead of guessing.

The README reports 24 to 51 times fewer tokens than pasting the whole book. It runs locally, so use it only with books you own.

Where to start

If you’re not sure what to try first:

  • Plan before coding: Brainstorming and Writing Plans from Superpowers.
  • Fix bugs without guessing: Systematic Debugging finds the root cause before it changes code.
  • Design UI: Frontend Design and UI UX Pro Max.
  • Check security: Differential Review from Trail of Bits.
  • Write your own: Skill Creator helps you build and test a skill.

Need more? awesome-agent-skills lists over 1,000 skills, and openai/skills is the official catalog for Codex.

Before you install

Warning
A skill can run scripts with your permissions. Read SKILL.md and every script before you install it, prefer known authors, and pin a version.

Check the license, too. Anthropic’s docx, pdf, pptx, and xlsx skills are source-available, not open source. Trail of Bits uses CC-BY-SA-4.0. A few repos have no license file, shown as See repo in the catalog.

Conclusion

A good skill is small. It teaches the agent one job and loads only when that job comes up. I’ll keep this list updated as I try more skills.
