Abstract

Have you ever come back to your Mac and realized it went to sleep before the work was finished? I have. 😅

Large uploads, iCloud syncs, video exports, photo imports, Docker containers, long Xcode builds, AI coding agents, or a huge game download all need time. You should not have to stay beside your Mac just to keep them running.

That is why I built Work Mode into Proximity Lock: Smart AutoLock. It keeps your Mac awake while your task continues, without asking you to give up the security protection that Proximity Lock provides.

  • The everyday problem behind Work Mode

Let’s get started.

The problem

Sleep is useful when we are finished with our Mac. The problem appears when the Mac goes to sleep before a long task is complete.

Maybe an Xcode build is still running. A video is being exported. Your photos are importing, or several gigabytes are still uploading to iCloud. These jobs do not need constant attention, but they do need the Mac to stay awake.

I have faced the same problem in my own workflow. I wanted to step away, continue with something else, and trust that the task would still be running when I came back.

That simple frustration became the primary motivation for Work Mode.

Work Mode: stay awake and protected

When Work Mode is active, your Mac stays awake so the current task can continue. At the same time, Proximity Lock remains your security companion.

The main idea is simple:

Keep your MacBook awake and secure while you work. Control Work Mode, display options, and protection remotely.

The Work Mode experience brings key controls together:

  • Stay awake: Keep long-running jobs active until you are ready to end Work Mode. → Benefit: No interrupted builds or broken cloud uploads.
  • Display options: Choose how the Mac display should behave while the task continues. → Benefit: Save display backlight power without going to sleep.
  • Distance-based locking: Keep proximity protection available when you step away. → Benefit: Auto-lock triggers if someone attempts physical access.
  • Café Mode alerts: Add another layer of protection when working in a shared or public place. → Benefit: Siren alarm + Instant photo capture to your iPhone.
  • Remote control and activity: Use the connected iPhone to check status and control your Mac remotely.

Work Mode has also been refined with better stability, clearer controls, and a smoother interface. The goal is not to add more things to manage. It is to let you start the mode, leave the task running, and come back when the work is done.

When is Work Mode useful?

Work Mode is helpful whenever your Mac needs to keep working longer than you do.

For example:

  • Running a long Xcode build or test process
  • Letting an AI coding agent complete a complex task
  • Uploading a large file or waiting for iCloud sync
  • Exporting a video or importing a photo library
  • Keeping Docker containers and development services active
  • Downloading a large game or software update

These are different jobs, but they share the same requirement: the Mac must stay awake long enough to finish.

You can start the task, enable Work Mode, and step away with full confidence.
