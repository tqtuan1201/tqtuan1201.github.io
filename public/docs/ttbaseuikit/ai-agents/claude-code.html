Claude Code

Supported

Claude Code can use the shared TTBaseUIKit Agent Skills package from Agents/Antigravity/Installation/ClaudeCode/. The installed skills include UIKit, SwiftUI, native component, bugfix, refactor, audit, and shared verification workflows.

🔧 Setup

Install the Claude Code package from the repository:

cd Agents/Antigravity/Installation/ClaudeCode
bash install.sh
claude skills list

Skills land in ~/.claude/skills/ and are available to Claude Code sessions.

Available workflows: /ttb-init, /ttb-uikit, /ttb-swiftui, /ttb-native, /ttb-bugfix, /ttb-refactor, and /ttb-audit.
